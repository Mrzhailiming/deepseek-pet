## 核心玩法

- **🐳 鲸鱼娘立绘**：AI 插画的「鲸鱼娘」—— 幼崽 / 少年 / 成年 / 传说 4 档形态 × 待机 / 进食 / 睡觉 / 饿了 / 兴奋 / 委屈 / 被摸 7 种状态，共 28 帧透明 APNG 精灵，随等级长大；养到头进化成代码猫 / 探索狐 / 文鸟 / 调试虫时还有专属名字。
- **🥕🐟🍖 Agent 干活就是在喂它**：你发消息、模型回话、工具跑完，分别喂萝卜 / 鱼 / 肉，食物从会话区**事件发生的位置**飞进右下角的卡片；这一口有多大看 **token 消耗量**，飘字直接写着烧了多少 token。
- **🔥 Combo 连击**：5 秒窗口内连续动作叠连击，白字 → 金字（震动）→ 彩虹（强震 + 光环 + 星星眼），经验倍率最高 ×3.0。
- **🍲 暴食**：连击顶到满格触发 15 秒暴食 BUFF——经验双倍、食物量再多两成，期间再顶格就续期。
- **😋 它还挑食**：最爱工具结果（同样的 token 多吃三成），但同一种连着喂 8 口就腻了（打七五折）——一轮里穿插着来，喂得最划算。
- **💤 心情 / 精力 / 睡眠**：两条进度条一直在动——干活涨心情、耗精力，空闲回精力；心情好经验多（0.8x ~ 1.2x），精力见底经验打八五折；**5 分钟没动静它就睡着**（回精力 ×3、饿得慢 ×0.5），你一发消息它就醒。
- **🤔😤😟 情绪写在脸上**：好奇 / 得意 / 担忧三维顶过阈值就换一副表情（挑眉大眼 / 眯眼得意 / 垂眉担忧）并念叨一句。它们**只管表情和台词，不碰任何数值**。
- **💬 它会说话**：吃到最爱夸一句、吃腻了抱怨、升级炫耀、吃饱喊撑、精力见底说困、深夜劝你歇会儿、隔 8 小时回来问「你去哪儿了」……二十来种场合，每句台词都是**算**出来的而不是随机的，不会刷成弹幕。
- **📊 技能树**：用它干的活养它——读写文件长「编码」💻、搜索抓网页长「探索」🔍、跑命令长「调试」🐛、写文档长「表达」✍️。技能练得够高，它才开始真的提醒你："`client.js` 改到第 3 次了"、"连着 3 条报错了，先看看上一条？"（一分钟最多一句，宁可少说）。
- **🐱🦊🐦🪲 进化**：Lv.10 之后，哪门技能一枝独秀它就分化成对应形态——代码猫 / 探索狐 / 文鸟 / 调试虫，整段 1.6s 变身动画 + 彩虹大字「进化 · 代码猫」；四门都平就留在 👑 传说金鲸。**分化只有一次**，之后长相不再变。
- **🥚 多宠物 + 蛋**：最多养 999 只。累计 token / 喂食次数 / 成就数 / 孵化数达成里程碑会掉落**六种蛋**（海洋 / 森林 / 代码 / 灵光 / 电路 / 彩虹），孵蛋可以给它起名，彩虹蛋随机种族；卡片上 ◀▶ 切换、★ 收藏、✏️ 改名，点指示器一眼看到有几只。
- **🏅 成就 + 每日任务**：14 枚成就（第一口、尝遍三味、满连击、大胃王、百万 token、连续一周……）+ 每天 3 条任务，达成即时结算零食和经验，成就墙整齐排开。
- **🧠 它记得你**：常改哪几个文件、最常用哪个工具、常在几点干活、跨过多少次报错；相处三天以上，睡醒那句会变成「又见面了，第 3 天…」。
- **🤚 摸头 / 拖动 / 本地存档**：点头像冒 💗 涨心情（1.5 秒冷却，摸够 50 次有徽章，连摸三下它脸红）；按住卡片拖动换位置，刷新还在；进度全在浏览器 localStorage（键 `dsh-pet-plugin/state`），多开标签页养的是同一只，**离开的这段时间它会慢慢饿**（最多按 24 小时结算，永远饿不死），回来先喂一口。
- **🍬 手动投喂**：零食 5 格、45 秒回一格、离线也在攒——不想看它饿的时候点一下 🍬 就好，点不出等级，也永远不会饿死。
- **♿ 减少动效**：系统开了「减少动效」就整套关掉——动画、瞳孔跟鼠标、闲下来的小动作全部不做，不打扰。

想改宠物名字 / 连击窗口 / 食物量 / 关特效，或者想看它到底是怎么在不改宿主仓库的前提下接上去的（事件从哪来、Combo 怎么算、APNG 精灵怎么进的单文件）——设计细节和全部可调配置都在 [`dsh-pet-plugin/plugin.md`](dsh-pet-plugin/plugin.md)。

## 30 秒装上

把 `dsh-pet-plugin` 目录放到 **dsh 仓库根目录**下，在仓库根执行：

```sh
pnpm dsh plugin --profile web add ./dsh-pet-plugin   # 装
pnpm dsh --profile web --dump-config                 # 确认（应看到 "# == dsh-pet-plugin" 和 pet-feed）
pnpm dsh web                                         # 起 Web
```

打开页面随便说句话 —— 鲸鱼娘就在右下角开始吃东西了。

装别人给你的 tarball 也一样（见 [打包分发](#打包分发)）：

```sh
pnpm dsh plugin --profile web add ./dsh-pet-plugin-0.4.0.tgz
```

卸载：

```sh
pnpm dsh plugin --profile web remove dsh-pet-plugin
```

> - 装完 / 卸完都要**重启 dsh** 才生效。
> - `web` profile 首次使用会自动从模板初始化（base + web-app）。
> - 用全局安装的 `dsh` 的话，把每条命令的 `pnpm dsh` 换成 `dsh`，参数完全一样。

## 打包分发

```sh
node pack.mjs                        # 在本目录执行
# 等价写法（实现就在包里）：
cd dsh-pet-plugin && node scripts/pack.mjs
```

产物落在 `dist/dsh-pet-plugin-<version>.tgz`，发给别人一条 `pnpm dsh plugin add` 装完即用，不需要构建、不需要联网。打包前会自动跑一遍清单校验、产物校验和冒烟测试。

自测（不需要装任何依赖）：

```sh
cd dsh-pet-plugin
node test/smoke.mjs
```
